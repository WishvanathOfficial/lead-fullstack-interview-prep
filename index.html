Questions
Good to know

    

      
Is it really free? Do I need an account?
Yes. There is nothing to install or sign up for. Open the portal and start. Your progress and code are saved in your own browser.

      
Who is it for?
Developers preparing for full stack, React or Node.js interviews, from mid-level to lead. The depth goes from the basics up to architecture, leadership and AI-assisted engineering.

      
How does the code practice work?
Each runnable exercise gives you starter code and a hidden test list. Press Run tests, see which cases pass, fix your code and try again. HTML and CSS exercises show a live preview instead.

      
How long does the roadmap take?
The plan is built for 8 to 12 weeks at roughly two hours a day. You can follow it week by week or jump to the subject you need most.

      
Can I move my progress to another device?
Yes. Use Export in the sidebar to download your progress as a file, then Import it on any other browser.
